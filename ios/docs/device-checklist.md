# Mac 与 iPhone 验收清单

云端编译和自动测试记录见 [cloud-validation.md](cloud-validation.md)。下面的交互功能及真机项目仍需逐项验收，自动测试不能代替这些操作。每项记录设备/系统/Xcode版本、步骤、预期、实际、截图或导出文件位置及通过/失败；失败修复后再验收。

## Mac / Xcode

- [ ] 按 README 构建原生真机及模拟器切片，安装精确版本 Pod 和 Swift 包，保存真实锁文件。
- [ ] `ShadowReader` Debug/Release 编译与链接；运行默认 XCTest，不能把语法检查当成此项通过。
- [ ] 开启 `RUN_NATIVE_IOS_TESTS=1`，266 词 G2P 与固定声学证据测试通过；记录被跳过的测试。
- [ ] 粘贴英文正文、HTTPS 网页，预览后保存；登录/脚本网页失败后能粘贴；长正文、缩写、引号、数字切句合理。
- [ ] Safari 分享 URL 与纯文本，扩展完成，主应用前台预览，一次消费；重启后收件箱仍可读取。
- [ ] 素材库、训练位置、录音、证据、难句与复习在应用重启后保留；重新开始训练仍可回放最近录音。
- [ ] 报告按本次每句最后尝试去重，跳过不计录音次数；数字发音分数为空。
- [ ] 内容模式：差异、重复词、缩写及识别争议回退；到期复习的 1/3/7 日规则和提前练习不推进轮次。
- [ ] 发音模式：手动下一句；辅助 Whisper 内容一致不推进复习、不给发音分数、不自动换句。
- [ ] 分析时下一句/上一句/重录/停止/退出：新任务仅在旧原生调用清理后执行，旧结果和旧播放取消不能覆盖或停止新任务。
- [ ] 导出 ZIP 包含 `recording.wav`、`result.json`、`target.txt`、说明；WAV SHA 与 JSON 相同，UTF-16 范围正确，词/音素/根分数均为 null。
- [ ] iPad 基础布局、横屏、长标题、VoiceOver 和大字体能操作。

## iPhone 真机

- [ ] 首次申请、拒绝和重新开启麦克风权限；由用户手动录音，无自动录音。
- [ ] 原音调速音调保持、循环、自适应留白排除准备/暂停时间，暂停/恢复、停止、跳过留白有效。
- [ ] 六种音色试听；四种 Edge 音色网络失败明确提示，缓存可再次播放，英语系统语音离线工作。
- [ ] Whisper 首次主动下载、取消、重试、损坏模型重新下载与 SHA 校验失败提示；发音评估不依赖 Whisper 下载。
- [ ] 下载模型、缓存原音并安装英语系统语音后，飞行模式完成录音→发音证据→Whisper 对比→回放→报告→重练；记录是否仍有网络请求。
- [ ] 5/10/15/30 秒实际英语跟读，每种至少 5 次；静音、极短、超过 30 秒、剪切音频、超长目标和模型失败显示未评估且保留原录音。
- [ ] 逐词/逐音素颜色和 IPA、竞争证据、覆盖率；片段回放为估计位置，禁止称为精确音素边界。
- [ ] 连续 20 次评估、反复重录和换句，确认串行推理、取消隔离及资源释放；用 Instruments 观察内存是否持续增长。
- [ ] 锁屏、进入后台、电话/系统音频中断、蓝牙或耳机移除；停止任务，保留已录音数据，回前台不自动录音或续训。
- [ ] 低内存/系统终止后重启数据保留；发音失败可继续听读、重录或跳过。
