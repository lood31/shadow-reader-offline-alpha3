# V1.1 真机验收清单（尚未完成）

记录手机型号、Android 版本、RAM、TTS 引擎、APK SHA-256。未测项目保留「未测」，不得填写性能结论。

## 数据与覆盖安装

- V0.1 导入文章、练到第二句、保存录音、选英式，直接覆盖安装 V1.1。
- 文章、句子、最远进度、录音保留，进度不是通过数，旧英式迁移 Sonia。
- 主动识别旧录音；删除测试文章，相关尝试 / 复习 / 录音清理，其他文章保留。

## 原音与留白

- 试听 Aria / Guy / Sonia / Ryan，同一句，确认音色和口音。
- 句中调速：0.5 / 0.9 / 1 / 1.35 / 2 倍；滑块、加减、档位即时生效，音高不变、不重置。
- 自由听读：四个比例，0 / 1 / 5 秒缓冲；关闭、暂停、跳过留白，循环每遍分别计时。
- 暂停原音 10 秒再继续，人为制造缓冲，确认留白排除暂停 / 准备 / 缓冲。
- 播放时预生成下一句，断网回放两句缓存，切音色不复用错误声音。
- 未缓存句断网明确失败，重试不换声，手动选系统离线语音才换声。

## 模型与音频

- 无模型可听读 / 录音，用户点击才下载；进度、取消、重试、断网失败、校验、重启就绪。
- 下载完成后飞行模式录音并识别；确认录音没有上传。
- 正确 / 漏词 / 替换 / 多词 / 词形变化各录一次，分别记录实际 ASR 文本和对齐结果。
- 静音和过短必须未评估；背景噪声、长停顿记录实际效果，不作为发音评分。
- 有效录音后录静音 / 极短录音，保留上一遍有效音频。普通有效重录只保留最新一遍。
- 识别中取消 / 切句 / 切页 / 后台 / 来电：结果不误写新句，无后台开麦 / 自动播放 / 自动推进。
- 短句和长句记录模型加载、识别耗时、峰值内存、温升和耗电；低内存失败明确提示。

## 重练、复习与报告

- 一致两秒后下一句，关闭则停留；差异停留，「再读一次」先示范，只提示手动开麦。
- 三次有效差异提示复习，允许继续；未评估不算有效差异。
- 「识别有误」不自动通过，撤回本次对复习 / 难句状态的影响，重识别独立 ID。
- 两次差异自动难句，手动标记可加入；再次前台刷新到期数。
- 用测试日期 / 数据验证次日、通过后 1 / 3 / 7 天、最后移出、再次差异回次日；失败 / 跳过不晋级。
- 复习跨文章逐句进行，最后进入报告；手动结束和跳过有记录。
- 同句三次失败后成功只计一句一致、四次尝试；最后跳过 / 未评估分别分类，不同文章相同句号不合并。
